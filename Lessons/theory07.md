## 📘 Functions

В этом конспекте ты познакомишься с функциями — одним из ключевых инструментов программирования, который позволяет структурировать код и переиспользовать логику.

---

# 🧠 1. Что такое функция

**Функция (function)** — это блок кода, который выполняет определённую задачу.

📌 Проще говоря:
функция — это «команда с именем», которую можно вызвать.

---

## 📦 Пример:

```javascript id="fn1"
function sayHello() {
  console.log("Hello");
}
```

---

👉 Важно:
код внутри функции **не выполняется**, пока ты её не вызовешь.

---

# ▶️ 2. Вызов функции

Чтобы выполнить функцию, нужно её вызвать:

```javascript id="fn2"
sayHello();
```

---

## 📊 Результат:

```javascript id="fn3"
Hello
```

---

---

# 🎯 3. Зачем нужны функции

Функции позволяют:

* не дублировать код
* разбивать программу на части
* улучшать читаемость

---

## 📦 Пример без функции:

```javascript id="fn4"
console.log("Hello, Ivan");
console.log("Hello, Maria");
```

---

## 📦 С функцией:

```javascript id="fn5"
function greet(name) {
  console.log("Hello, " + name);
}

greet("Ivan");
greet("Maria");
```

---

👉 Код стал гибче.

---

# 🧾 4. Параметры и аргументы

---

## 🔹 Формальные параметры

**Формальные параметры** — это переменные в объявлении функции.

```javascript id="fn6"
function greet(name) {
  console.log(name);
}
```

👉 `name` — параметр

---

---

## 🔹 Аргументы

**Аргументы** — это реальные значения при вызове функции.

```javascript id="fn7"
greet("Ivan");
```

👉 `"Ivan"` — аргумент

---

## 🧠 Важно:

* параметр — «переменная»
* аргумент — «значение»

---

# 🔄 5. Возврат значения (return)

---

## 🔹 Функция с return

```javascript id="fn8"
function sum(a, b) {
  return a + b;
}

let result = sum(2, 3);
```

---

👉 `result = 5`

---

## 🧠 Что делает return:

* завершает функцию
* возвращает значение

---

---

## 🔹 Функция без return

```javascript id="fn9"
function printSum(a, b) {
  console.log(a + b);
}
```

---

👉 Ничего не возвращает (возвращает `undefined`)

---

## ⚖️ Разница:

| С return                     | Без return                 |
| ---------------------------- | -------------------------- |
| возвращает значение          | просто выполняет действие  |
| можно использовать результат | нельзя сохранить результат |

---

# 📐 6. Сигнатура и контракт функции

---

## 🔹 Сигнатура

**Сигнатура функции** — это:

* имя функции
* список параметров

---

## 📦 Пример:

```javascript id="fn10"
function sum(a, b)
```

---

---

## 🔹 Контракт

**Контракт функции** — это:

* что функция принимает
* что она возвращает
* что она делает

---

## 📦 Пример:

```javascript id="fn11"
function sum(a, b) {
  return a + b;
}
```

---

📌 Контракт:

* принимает два числа
* возвращает сумму

---

👉 Важно:
контракт должен быть понятен и предсказуем.

---

# 🏷️ 7. Правила именования функций

---

## 📌 Рекомендуется:

* использовать понятные имена
* использовать глаголы

---

## 📦 Примеры:

```javascript id="fn12"
calculateTotal()
getUserName()
printMessage()
```

---

---

## ❌ Плохие примеры:

```javascript id="fn13"
f()
doIt()
x()
```

---

👉 Имя должно объяснять, что делает функция.

---

# 🧪 8. Практический пример

```javascript id="fn14"
function calculateTotal(price, quantity) {
  return price * quantity;
}

let total = calculateTotal(100, 3);

console.log("Total: " + total);
```

---

## 📊 Результат:

```javascript id="fn15"
Total: 300
```

---

# 🐞 9. Работа с дебаггером

В Visual Studio Code можно:

---

## 📌 Отслеживать:

* вход в функцию
* значения параметров
* результат выполнения

---

## 🧠 Пример:

```javascript id="fn16"
function sum(a, b) {
  return a + b;
}

let result = sum(2, 3);
```

---

## 📊 В дебаггере:

```text id="fn17"
a → 2
b → 3
result → 5
```

---

👉 Видно, как передаются данные.

---

# ⚠️ 10. Частые ошибки

## ❌ Не вызвать функцию

```javascript id="fn18"
sayHello; // не выполнится
```

---

## ❌ Забыть return

```javascript id="fn19"
function sum(a, b) {
  a + b;
}
```

---

## ❌ Неправильные аргументы

```javascript id="fn20"
sum(2); // не хватает аргументов
```

---

## ❌ Плохие имена функций

→ сложно понять код

---

# 🧠 Важные выводы

* функция — это переиспользуемый блок кода
* параметры — это переменные функции
* аргументы — реальные значения
* функции бывают:

  * с return
  * без return
* сигнатура — имя и параметры
* контракт — поведение функции
* хорошие имена делают код понятным
* функции — основа структурирования программы
