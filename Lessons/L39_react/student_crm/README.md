# STUDENT CRM - React + Vite
Учебный проект "Система управления студентами", выполненный на React с использованием сборщика Vite.

## Технологический стек:
- **Frontend:** React (JSX)
- **Сборщик:** Vite
- **Стилизация:** CSS3
- **Язык:** JavaScript (ES6+)

## Функциональные возможности:
- **Компонентная структура**
- **Передача данных** через props
- **Индикатор статуса** (`StatusBadge`) - отображение статуса студента "Активен" / "Пауза"
- **Условный рендеринг** Автоматическая пометка студентов младше 18 лет
- **Обработка пустого состояния**: Если студенты в списке отсутствуют - отображается понятное сообщение
- **Динамический счётчик** - количество студентов отображается на основе длины массива
- **Локальные данные:** работа со статическим массивом из 5 студентов с уникальным id


## Структура проекта
src/
├── components/
│   ├── Header.jsx       # Заголовок приложения и общая информация
│   ├── StudentList.jsx  # Компонент-контейнер для списка карточек
│   ├── StudentCard.jsx  # Карточка отдельного студента
│   ├── StatusBadge.jsx  # Индикатор статуса ("Активный" / "Пауза")
│   └── Footer.jsx       # Подвал страницы
├── data/
│   └── students.js      # Локальный массив с данными студентов
├── App.jsx              # Главный компонент приложения
├── App.css              # Основные стили компонентов
├── index.css            # Глобальные стили и переменные
└── main.jsx             # Точка входа Vite / React
