# COURSE CATALOG - React + Vite
Учебный проект "Course Catalog", выполненный на React с использованием сборщика Vite.

## Технологический стек:
- **Frontend:** React (JSX)
- **Сборщик:** Vite
- **Стилизация:** CSS3
- **Язык:** JavaScript (ES6+)

## Функциональные возможности:
- **Статические локальные данные:** массив из 4 курсов с уникальным `id`
- **Отображение каталога:** рендеринг списка карточек курсов
- **Передача данных:** Компоненты получают данные через props
- **Индикатор статуса:** (`AvailabilityBadge`) - отображение статуса курса "Available" / "Closed"
- **Условный рендеринг:** курс, стоимость которого превышает 400, помечается как "Premium Course"
- **Обработка пустого состояния:** Если курсы в списке отсутствуют - отображается сообщение "No courses available"
- **Компонент-обёртка `Card`:** универсальный контейнер с использованием prop `children`


## Структура проекта
```
src/
├── components/
│   ├── Header.jsx              # Заголовок приложения и общая информация
│   ├── CourseList.jsx          # Компонент-контейнер для списка карточек
│   ├── CourseCard.jsx          # Карточка отдельного курса
│   ├── Card.jsx                # Универсальный компонент для карточек (children)
│   ├── AvailabilityBadge.jsx   # Индикатор статуса ("Available" / "Closed")
│   └── Footer.jsx              # Подвал страницы
├── data/
│   └── courses.js              # Локальный массив с данными курсов
├── App.jsx                     # Главный компонент приложения
├── App.css                     # Основные стили компонентов
├── index.css                   # Глобальные стили
└── main.jsx                    # Точка входа Vite / React
```

## Запуск проекта
1. Клонируйте репозиторий
```git clone https://github.com/yulialopaev/javascript_66.git```
```cd javascript_66/Homework/hw39_course_catalog```
2. Установите зависимости
```npm install```
3. Запустите проект
```npm run dev```
